# New Year Greeting Page
A China New Year festival greeting page for APP embedding, red-gold festive style, independent multi-page jump mode.

[中文](README.md)
[English](b.md)
[Español](d.md)

## Language Page List
- `newyear-zh.html` Chinese
- `newyear-en.html` English
- `newyear-fr.html` Français
- `newyear-es.html` Español

## Function Description
- Animated flowing gradient background, glowing text and falling particle effects for China New Year
- Users can input and submit China New Year wishes
- Language links at the top right, click to jump to corresponding language page
- Keep the about software entry at the bottom
- Mobile adaptive, suitable for WebView embedding
